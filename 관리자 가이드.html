관리자 가이드: 스프레드시트 연동

모든 순위는 Google 스프레드시트 하나에서 관리합니다. 시트를 수정하면 사이트에 자동으로 반영되며, 열려 있는 페이지도 2분마다 다시 불러옵니다.

01스프레드시트 만들기

  1. Google Sheets에서 새 스프레드시트를 만들고 아래 7개 탭을 만드세요: Main Misc Packs Unverified Pending Records Changelog
  2. 각 탭의 첫 행에 아래 헤더를 그대로 넣으세요. 템플릿 CSV를 내려받아 파일 → 가져오기로 넣으면 편합니다.
  3. 공유 → 링크가 있는 모든 사용자: 뷰어로 설정하세요.
  4. 주소의 /d/와 /edit 사이 문자열(시트 ID)을 복사해 js/config.js의 SHEET_ID에 붙여넣으세요.

02순위는 행 순서로 정해집니다

헤더 다음 첫 행이 1위입니다. 새 타워를 3위에 넣으려면 3위 행 위에 행을 삽입하면 됩니다. 기존 3위부터 그 아래 타워들은 자동으로 한 칸씩 밀려나고, 포인트도 다시 계산됩니다.

03리스트 탭 열 구성 (Main / Misc / Unverified / Pending)

열설명
id고유 ID (영문 소문자·하이픈). 비우면 이름으로 자동 생성. 순위가 바뀌어도 상세 페이지 주소가 유지되도록 한 번 정하면 바꾸지 마세요.
name타워 이름 (필수)
game게임 이름 (JToH, Mystic Towers 등)
difficulty난이도 등급 (Insane, Extreme, Terrifying, Catastrophic, Horrific …) — 색상 자동 표시
creators제작자, 쉼표로 구분
verifier검증자 (Unverified 탭은 비워두기)
videoYouTube 링크 — 썸네일과 상세 페이지 영상이 자동 표시
place_idRoblox Place ID(숫자) 또는 게임 링크
note비고 (상세 페이지에 표시)

Packs 탭은 위 열에 더해 towers 열을 사용합니다. 포함된 타워의 id를 세미콜론(;)으로 구분해 적으세요.

05제출 폼 연결 (Google Form)

  1. Google Form 두 개(기록 제출 / 타워 제출)를 만들고, 사이트 제출 페이지와 같은 질문을 단답형으로 추가하세요.
  2. 폼의 응답 → 스프레드시트에 연결을 켜면 제출 내용이 같은 스프레드시트의 새 탭에 쌓입니다. 검토 후 Records 또는 Pending 탭에 옮기면 사이트에 반영됩니다.
  3. 폼 미리보기에서 ⋮ → 미리 채워진 링크 받기로 각 질문의 entry.XXXX 번호를 확인해 js/config.js의 FORMS에 넣고, action에 https://docs.google.com/forms/d/e/폼ID/formResponse를 입력하세요.
FORMS: {
  record: {
    action: "https://docs.google.com/forms/d/e/1FAIpQ.../formResponse",
    fields: { player: "entry.123456", list: "entry.234567", tower: "entry.345678", video: "entry.456789", raw: "entry.567890", note: "entry.678901" }
  }, ...

06문제 해결

  • 사이드바의 상태 표시가 회색(샘플)이면 SHEET_ID가 비어있는 것입니다.
  • 빨간색(실패)이면 공유 설정이 "링크가 있는 모든 사용자"인지, 탭 이름이 config.js의 TABS와 일치하는지 확인하세요.
  • Google 측 캐시로 인해 수정 후 반영까지 최대 1~2분 걸릴 수 있습니다.
